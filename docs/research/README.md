# Рабочие отчёты исследования

Отчёты по отдельным ячейкам исследования ландшафта rate limiting. Сводка и
выводы — в [`../RESEARCH.md`](../RESEARCH.md).

Файлы кладутся сюда, а не во временную директорию: первая попытка исследования
была утрачена целиком, когда машина перезагрузилась и `/tmp` очистился.
Репозиторий — единственное надёжное место для промежуточных результатов.

Маркеры достоверности — как в `RESEARCH.md`: **[проверено]** (прогон или
первоисточник), **[из отчёта]** (требует перепроверки).
