# ratelimit-lab

Учебная **библиотека rate limiting на Go** с честным бенчмарк-сьютом. Три
классических алгоритма ограничения частоты для одного процесса — **token
bucket**, **sliding window**, **leaky bucket** — плюс **lock-free** (CAS-based)
вариант token bucket, и сравнение их throughput/latency под конкурентной
нагрузкой.

Это соло pet-проект с приоритетом **обучения**: конкурентные примитивы
(atomic vs mutex vs lock-free CAS-циклы) и алгоритмическая корректность под
нагрузкой. Не бизнес, не сервис — чистая библиотека стандартной библиотеки Go
без внешних зависимостей и без инфраструктуры.

## Что внутри

- `internal/limiter/` — ядро: контракт `Limiter` (`Allow() bool` / `AllowN`) и
  реализации алгоритмов. Все безопасны для конкурентного использования.
- `cmd/bench/` — CLI-харнесс: гоняет лимитеры под нагрузкой и печатает
  сравнительную таблицу (реализация — Этап 5).

## Статус

Этап 0 (бутстрап): скелет и документация на месте, `go build`/`go vet` чисты,
алгоритмы — заглушки `TODO(Этап N)`. Реализация идёт по Этапам, см. план.

## Быстрый старт (для разработки)

```bash
export PATH="$HOME/sdk/go/bin:$PATH"
go build ./...
go vet ./...
go test -race ./...      # появится с первыми реализациями (Этап 1+)
```
